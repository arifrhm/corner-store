Artifact-bound runtime

On the first start after deployment, Studio activates the selected demo Manifest and venues through the CLI, then launches the RFQ backend, Operator API and Dashboard against this project’s verified artifact, scenario and current RPC. It does not deploy a second stack.

Manual evidence checklist

Checking an item records that an operator reviewed the step. It does not approve a Maker, authorize a signer, transfer tokens or create a multisig transaction.
